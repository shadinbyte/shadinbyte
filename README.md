### 🚀 Featured Projects

#### 🎙️ [AI Voice Agent](https://github.com/shadinbyte/ai-voice-agent)
A conversational voice agent, built on Retell AI, that answers phone calls and handles appointment booking, rescheduling, and cancellations on its own. It has safety checks built in so it never improvises on things it doesn't actually know, like pricing or medical details.
`Retell AI` `Python` `Cal.com API`

#### 🗂️ [Enterprise Knowledge Assistant](https://github.com/shadinbyte/gdrive-rag-slack)
An internal RAG system that lets a team search their own Google Drive documents and get accurate, source-backed answers right inside Slack. Combines keyword search, vector search, and reranking so answers stay grounded in the actual documents instead of guessing.
`Python` `LangGraph` `ChromaDB` `Slack API`

#### 🔍 [B2B Lead Generation Pipeline](https://github.com/shadinbyte/marketing-intel-scraper)
A pipeline that finds and enriches business leads by industry and location. Pulls data from Google Maps and runs it through an async layer that adds extra details to each lead automatically, so the output is ready to use, not just a raw list.
`Python` `Apify` `httpx` `asyncio`
